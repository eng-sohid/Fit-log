FitLog

Hi, I'm Sohid

FitLog is a simple fitness and workout website where users can browse different workouts and view detailed information about each exercise.

I built this project to practice my Next.js and frontend development skills.

===================> Features <==================================|
=> Browse a library of workouts
=> View detailed information for each workout
=> Dynamic workout pages
=> Fully responsive design
=> Simple and easy navigation

==================> Tech Stack <===============================|
Next.js
React
TypeScript / JavaScript
Tailwind CSS
