# FitLog

Hi, I am Sohid. I created this project named **FitLog** using **Next.js, JavaScript, TypeScript, React, and Tailwind CSS**. FitLog is a simple fitness and workout website where users can explore different workouts and see detailed information about each exercise. The main features of this project are browsing workouts, viewing workout details, dynamic pages, responsive design, and easy navigation. I created this project to practice my Next.js and frontend development skills.
